# Devops-pipeline-cpp
🚀 DevOps End-to-End Pipeline Project (C++)
📌 Overview

This project implements a complete end-to-end DevOps pipeline for a C++ application. It demonstrates how modern DevOps practices can be applied to build, package, and deploy a production-ready service using containerization and orchestration tools.

The application is developed in C++, containerized using Docker, automated through a CI/CD pipeline with Jenkins, and deployed on a Kubernetes cluster.

🎯 Objectives
Develop a lightweight C++ application
Containerize the application using Docker
Automate build and deployment using Jenkins
Deploy and manage the application using Kubernetes
Establish a complete CI/CD workflow from code commit to deployment

🛠️ Tech Stack
Language: C++
Containerization: Docker
CI/CD: Jenkins
Orchestration: Kubernetes
Version Control: Git & GitHub

🏗️ Architecture
Developer → GitHub → Jenkins → Docker → Kubernetes

Code is pushed to GitHub
Jenkins triggers the CI/CD pipeline
Application is built and packaged into a Docker image
Docker image is pushed to a container registry
Kubernetes deploys and manages the application
