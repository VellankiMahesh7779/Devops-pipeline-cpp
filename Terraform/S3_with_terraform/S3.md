## ✅ Day 3 - S3 Bucket Creation and Versioning

### Topics Covered

* Created an Amazon S3 bucket using Terraform.
* Learned that S3 bucket names must be globally unique.
* Used `random_id` resource to generate a unique bucket name.
* Enabled S3 Bucket Versioning.
* Configured bucket tags for resource identification.

### Concepts Learned

* AWS S3 Bucket
* Globally Unique Bucket Names
* Terraform `random_id` Resource
* S3 Bucket Versioning
* Terraform Outputs and Resource Dependencies
