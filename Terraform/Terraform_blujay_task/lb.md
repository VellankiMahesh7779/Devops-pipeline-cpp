## ✅ Day 5 - EC2, Key Pair, ALB, Target Group and Auto Scaling Group

### Topics Covered

* Created an EC2 instance using Terraform.
* Created and attached an AWS Key Pair for secure SSH access.
* Connected to the EC2 instance using the uploaded SSH key.
* Created an Application Load Balancer (ALB).
* Configured a Target Group for routing traffic to EC2 instances.
* Created a Launch Template for Auto Scaling.
* Configured an Auto Scaling Group (ASG) to automatically manage EC2 instances.

### Concepts Learned

* AWS Key Pair
* Secure SSH Access
* Security Groups
* EC2 Instance Provisioning
* Application Load Balancer (ALB)
* Target Groups
* Launch Template
* Auto Scaling Group (ASG)
* High Availability
* Infrastructure as Code (Terraform)
